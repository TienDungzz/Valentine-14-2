# Valentine Red — Tài liệu frontend 3D

Website một trang dùng Vite, JavaScript ES modules và Three.js. Trải nghiệm chính: hai người ghép hai nửa hộp trái tim, khám phá 14 chocolate đen và 14 lời nhắn riêng.

project-standards.json chỉ khai báo đường dẫn thực sự có trong website. example-standards/ là nguồn tham khảo riêng, không nằm trong bộ docs áp dụng hoặc artifact build.

Không có backend/API, tài khoản, database, bộ chọn locale hoặc light/dark mode trong bản hiện tại. Không yêu cầu các thành phần này để website được kiểm tra hoặc build.
